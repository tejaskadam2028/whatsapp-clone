# 📱 WhatsApp Clone

A WhatsApp Clone built using Kotlin, Jetpack Compose, Firebase Authentication, Hilt, and MVVM Architecture.

## ✨ Features

- Splash Screen
- Welcome Screen
- Phone Number Authentication
- OTP Verification
- Basic Profile Setup
- Image Picker

## 🛠️ Tech Stack

- Kotlin
- Jetpack Compose
- Firebase Authentication
- Hilt
- MVVM
- Navigation Compose
